# TASKS-2: Add a project license

Status: blocked

## Description

Before publishing the project, decide between a public domain dedication via The Unlicense (`UNLICENSE`) and the MIT License. Confirm the rights holders approve releasing the imported code under the chosen terms. Record the decision, add the standard text at the repository root, and preserve any required third-party notices.

## Comment (2026-11-19T14:53:47Z)

In the end, I've decided to go with the UNLICENSE. I didn't actually write the code, and the LLM that wrote it was trained on humanity's collective output (much of it subsumed into the training data without license). It seems pointless at this point to license new projects that are AI-generated under a regime that dates back to a different era.
